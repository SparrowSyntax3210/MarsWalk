# Mars named-feature locations

This file contains the center points for all 2,052 Mars features in the USGS Astrogeology Science Center / IAU Mars nomenclature shapefile downloaded on 2026-10-25.

Source and nightly GIS downloads: https://planetarynames.wr.usgs.gov/GIS_Downloads
Source archive: https://asc-planetarynames-data.s3.us-west-2.amazonaws.com/MARS_nomenclature_center_pts.zip

The gazetteer stores east longitude. Values in the mars-locations.json file are normalized to -180° through 180°; latitudes are planetocentric. The source feature URL and feature type are retained for each record.
